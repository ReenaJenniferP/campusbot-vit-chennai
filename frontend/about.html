About CampusBot

CampusBot is a student assistant interface designed to demonstrate a modern, multi-page web programming experience with a clean AI-inspired visual style.

◎

Objective

To build a smart campus assistant experience that feels polished, modern, and easy to use for students navigating campus information.

⚙

Tech Stack

HTML, CSS, JavaScript, Python, FastAPI, FAISS, and a themed multi-page frontend designed for a modern chatbot-inspired experience.
